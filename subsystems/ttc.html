02 / OVERVIEW

TT&C handles the bidirectional radio link…

In BIO-LUX the two responsibilities are consolidated…

Within a sun-synchronous orbit at 671 km…

Ground passes ~7 / day (total)
Avg. pass window ~7.5 min
Daily data budget 1.1 GB (S-band cap.)

03 / SPECIFICATIONS

Key specifications

Uplink band UHF Amateur 437 MHz
Downlink band S-Band 2.25 GHz
Uplink data rate 9.6 kbps
Downlink data rate 1.6 Mbps
TX RF power 1.0 W
TC modulation GMSK —
TM modulation OQPSK CCSDS
Framing protocol CCSDS TM / TC
Worst-case link margin > 3 dB
OBC Xiphos Q8S Zynq MPSoC
Mass memory eMMC 2x 128 GB
Subsystem mass (alloc.) ~0.44 kg
