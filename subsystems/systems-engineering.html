02 / OVERVIEW

Systems Engineering orchestrates the Concept of Operations (ConOps), failure management, and strict mass/power budgets[cite: 6].

BIO-LUX operates semi-autonomously across six defined modes. The FDIR (Failure Detection, Isolation, and Recovery) architecture employs a five-layer defense, from silicon-level error correction to ground-commanded recovery[cite: 6].

A rigorous budgeting philosophy ensures that the 12 kg limit is met with a comfortable 2.7 kg margin, and power is conservatively allocated to support all four payload profiles[cite: 6].

05 / FDIR LOGIC

FDIR Architecture

L0

SILICON LAYER

Hardware Level

Mitigates RAM/eMMC errors using EDAC and TMR mechanisms. Responds in <1 ms[cite: 6].

L1

TASK LAYER

Software RTOS

Handles execution overruns and missed deadlines using FreeRTOS hooks and schedule resets[cite: 6].

L2

SUBSYSTEM LAYER

Hardware Node

Monitors out-of-bounds parameters and undervoltage. Commands safe state or PCDU power cycles[cite: 6].

L3

SYSTEM LAYER

Global Mode Manager

Reacts to persistent L2 failures or critical attitude faults by forcing transitions to Safe Mode[cite: 6].

L4

GROUND LAYER

Human-in-the-Loop

Invoked when on-board recovery is exhausted. Operations Centre commands OBC reboots or software image fallbacks[cite: 6].

06 / DESIGN DECISIONS

System-Level Decisions

Design for 12 kg Hard Limit

The 6U platform is structured to ensure that even under worst-case structural and payload configurations, the total wet mass (8.11 kg) preserves a robust margin against standard deployer mass limits (12 kg), increasing launch opportunity flexibility[cite: 6].

Zero Debris Approach Compliance

The mission implements a rigorous End-of-Life phase to satisfy ESA's Zero Debris policy. A dedicated deorbiting maneuver (utilizing electric propulsion) forces atmospheric re-entry within a 5-year timeline[cite: 6].
